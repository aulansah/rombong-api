6Docker & Makefile, pelan-pelan

Masalah yang diselesaikan Docker

Backend butuh tiga "mesin" sekaligus: program Go-nya, database PostgreSQL, dan cache Redis. Tanpa Docker, kamu harus menginstal ketiganya di laptop dengan versi yang pas, dan sering muncul masalah "di laptopku jalan, di laptopmu error".

😩 Tanpa Docker

  1. Instal Go versi tertentu
  2. Instal PostgreSQL, buat user & database
  3. Instal Redis
  4. Atur port, password, dan setelan satu per satu
  5. Laptop teman beda versi → error lain lagi

😌 Dengan Docker

Cukup satu perintah: docker compose up. Docker menyalakan tiga "kotak" yang isinya sudah lengkap dan sama persis di laptop siapa pun:

📦 apiprogram Go yang sudah jadi
🗄️ postgresdatabase PostgreSQL 16
⚡ rediscache Redis 7

Kotak-kotak ini disebut container. Resep isi kotak api ada di Dockerfile; daftar kotak yang dinyalakan bersama ada di docker-compose.yml.

📜

Dockerfile = resep membuat satu kotak

Tahap 1 (builder): ambil Go, unduh library, ubah kode menjadi satu file program. Tahap 2: pindahkan file program itu saja ke kotak Alpine Linux yang kecil (±20 MB), jalankan sebagai user biasa (bukan admin) supaya aman, dan cek kesehatannya lewat /health setiap 15 detik.

🧩

docker-compose.yml = daftar kotak + kabelnya

Menyalakan api, postgres, redis bersamaan, menyambungkan mereka di jaringan internal, membuka port 8080 ke laptop, menyimpan data database di volume supaya tidak hilang saat dimatikan, dan menunggu database siap sebelum api dinyalakan.

Makefile = tombol remote untuk perintah panjang

Perintah programmer sering panjang dan susah diingat. Makefile memberi nama pendek. Ketik make + nama:

Contoh: make test-integration sebenarnya menjalankan go test -tags integration -race -count=1 ./tests/.... Makefile hanya jalan pintas; tanpa Makefile pun semuanya tetap bisa dijalankan manual. Di Windows, make perlu diinstal dulu (misalnya lewat Git Bash atau Chocolatey).

7Cara menjalankan, versi singkat

Backend

Pakai Docker (paling gampang)

  1. Instal Docker Desktop, lalu buka aplikasinya
  2. Buka terminal di folder go-ecommerce-api
  3. cp .env.example .env (bikin file setelan)
  4. docker compose up --build
  5. Buka http://localhost:8080/docs: daftar semua endpoint, bisa dicoba langsung
Aplikasi

Flutter di emulator

  1. Instal Flutter 3.35+ dan Android Studio (untuk emulator)
  2. Buka terminal di folder ecommerce_app
  3. Sekali saja: flutter create --org com.aulansah --project-name ecommerce_app . (membuat folder android/ios)
  4. flutter pub get (unduh library)
  5. Pastikan backend sudah jalan, lalu flutter run
Login admin bawaan: admin@example.com / Admin12345 (diatur di .env). Pelanggan bisa daftar sendiri dari aplikasi.
