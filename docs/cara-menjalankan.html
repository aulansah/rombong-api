①Nyalakan backend

Pilih salah satu jalur.

  1. Buka Docker DesktopTunggu sampai di pojok kiri bawah tertulis Engine running.
  2. Buka terminal di folder backend
    PowerShell
    cd "I:\Fullstack Web Developer and Flutter Developer\rombong-api"
  3. Nyalakan semuanya
    PowerShell
    docker compose up --build
    Pertama kali butuh beberapa menit (mengunduh image Go, PostgreSQL, Redis, lalu build). Berikutnya hanya beberapa detik. File .env tidak diperlukan di jalur ini; setelan sudah ada di docker-compose.yml.
  4. Pastikan sehat Buka di browser: http://localhost:8080/health
    ✅ Berhasil jika muncul {"database":"up","redis":"up","status":"ok"}
  5. Coba API lewat Swagger Buka http://localhost:8080/docs: semua 34 endpoint bisa dicoba dari browser. Untuk endpoint yang butuh login: jalankan POST /auth/login dengan akun admin, salin access_token, klik tombol Authorize, tempel token.

Mematikan & mereset

PowerShell
# di terminal yang sedang berjalan: tekan Ctrl+C, lalu
docker compose down        # matikan, data tetap tersimpan
docker compose down -v     # matikan DAN hapus semua data (mulai dari nol)
docker compose up -d       # nyalakan di background (terminal bisa ditutup)
docker compose logs -f api # lihat log backend

Database dan Redis tetap lewat Docker (Redis tidak tersedia resmi untuk Windows), tapi program Go dijalankan langsung. Cocok saat kamu sedang mengubah kode backend.

  1. Nyalakan hanya database & Redis
    PowerShell · folder rombong-api
    docker compose up -d postgres redis
  2. Buat file setelan (sekali saja)
    PowerShell
    copy .env.example .env
    Isinya sudah cocok untuk lokal (DB_HOST=localhost, akun admin admin@example.com / Admin12345).
  3. Jalankan backend
    PowerShell
    go run ./cmd/api
    Saat pertama, Go mengunduh library (butuh internet). Tabel database dibuat otomatis (migration) sebelum server mulai menerima request.
  4. Cek localhost:8080/health dan localhost:8080/docs seperti jalur Docker.
⚠️ Jangan jalankan jalur Docker penuh dan jalur ini bersamaan: keduanya memakai port 8080. Kalau sebelumnya pernah docker compose up, matikan container api dulu: docker compose stop api.
🔑 Akun admin bawaan: admin@example.com / Admin12345 (dibuat otomatis saat backend menyala). Akun pelanggan didaftarkan dari aplikasi.

②Isi produk contoh

Database baru masih kosong, jadi katalog di aplikasi akan kosong. Skrip ini login sebagai admin lalu membuat 3 kategori dan 7 produk lewat API (sama seperti yang dipakai di showcase).

  1. Pastikan backend sudah menyala (langkah ①).
  2. Buka PowerShell baru, tempel seluruh skrip di bawah, tekan Enter. Jalankan sekali saja; kalau dijalankan lagi, kategori yang sama ditolak (409) karena namanya harus unik.
    PowerShell · seed-produk.ps1
    $base = "http://localhost:8080/api/v1"
$login = Invoke-RestMethod -Method Post -Uri "$base/auth/login" -ContentType "application/json" `
  -Body (@{ email = "admin@example.com"; password = "Admin12345" } | ConvertTo-Json)
$h = @{ Authorization = "Bearer " + $login.data.tokens.access_token }

function New-Category($name) {
  $r = Invoke-RestMethod -Method Post -Uri "$base/categories" -Headers $h -ContentType "application/json" `
    -Body (@{ name = $name } | ConvertTo-Json)
  return $r.data.id
}
$minuman = New-Category "Minuman"
$snack   = New-Category "Makanan Ringan"
$dapur   = New-Category "Perlengkapan Dapur"

$produk = @(
  @{ name = "Kopi Arabika Gayo 250g";     price = 85000;  stock = 24; category_id = $minuman; description = "Biji kopi single origin dari Gayo, sangrai medium." },
  @{ name = "Teh Hijau Melati 100g";      price = 32000;  stock = 40; category_id = $minuman; description = "Teh hijau dengan bunga melati asli." },
  @{ name = "Cokelat Bubuk Premium 200g"; price = 54000;  stock = 15; category_id = $minuman; description = "Kakao murni tanpa gula tambahan." },
  @{ name = "Keripik Singkong Balado";    price = 18000;  stock = 60; category_id = $snack;   description = "Keripik singkong renyah bumbu balado." },
  @{ name = "Kacang Mete Panggang 250g";  price = 76000;  stock = 12; category_id = $snack;   description = "Mete dipanggang tanpa minyak." },
  @{ name = "French Press 600ml";         price = 149000; stock = 8;  category_id = $dapur;   description = "Kaca borosilikat, saringan stainless." },
  @{ name = "Edisi Terbatas: Kopi Luwak"; price = 450000; stock = 1;  category_id = $minuman; description = "Stok 1, untuk mencoba rebutan stok." }
)
foreach ($p in $produk) {
  $r = Invoke-RestMethod -Method Post -Uri "$base/products" -Headers $h -ContentType "application/json" -Body ($p | ConvertTo-Json)
  Write-Host "OK  $($r.data.name)  stok $($r.data.stock)"
}
  3. Cek localhost:8080/api/v1/products menampilkan 7 produk.
Alternatif tanpa skrip: setelah aplikasi jalan, login sebagai admin → ikon admin di katalog → tab Kategori dan Produk → tombol +.

③Jalankan aplikasi Flutter

Persiapan sekali saja

  1. Buka terminal di folder aplikasi
    PowerShell
    cd "I:\Fullstack Web Developer and Flutter Developer\rombong-app"
  2. Buat folder platform (android, web) Repo sengaja tidak menyimpannya; perintah ini membuatnya tanpa menimpa kode yang sudah ada.
    PowerShell
    flutter create --org com.aulansah --project-name rombong --platforms=android,web .
flutter pub get
  3. Izinkan HTTP ke backend lokal (wajib untuk Android) Android 9 ke atas memblokir HTTP tanpa S. Backend lokal memakai http://, jadi buka file android\app\src\main\AndroidManifest.xml dan tambahkan atribut ini ke tag <application:
    android/app/src/main/AndroidManifest.xml
    <application
    android:label="rombong-app"
    android:name="${applicationName}"
    android:icon="@mipmap/ic_launcher"
    android:usesCleartextTraffic="true">
    ⚠️ Tanpa ini, login gagal dengan pesan "Tidak bisa terhubung ke server" walau backend menyala. Di production, backend harus memakai HTTPS dan atribut ini dihapus.
  4. (Opsional) simpan perubahan ke Git git add . ; git commit -m "chore: add android and web platform folders"

Pilih tempat menjalankan

  1. Nyalakan emulator Android Studio → Device Manager → tombol ▶ pada salah satu perangkat (buat dulu jika belum ada, misalnya Pixel dengan Android 14). Atau lewat terminal:
    PowerShell
    flutter emulators                 # lihat daftar emulator
flutter emulators --launch <id>   # ganti <id> dengan salah satu dari daftar
  2. Jalankan aplikasi
    PowerShell · folder rombong-app
    flutter run
    Tidak perlu mengatur alamat: di emulator Android, aplikasi otomatis memakai http://10.0.2.2:8080 (alamat khusus emulator untuk laptop).
  3. Saat aplikasi berjalan tekan r di terminal untuk hot reload setelah mengubah kode, R untuk restart, q untuk keluar.
  1. Jalankan di Chrome dengan port 3000
    PowerShell · folder rombong-app
    flutter run -d chrome --web-port 3000
    ⚠️ Port 3000 penting: backend hanya mengizinkan browser dari http://localhost:3000 (setelan CORS). Dengan port acak, request diblokir browser.
Di versi web, token disimpan di penyimpanan browser (flutter_secure_storage versi web), tidak sekuat Keystore Android. Untuk demo cepat ini cukup.
  1. HP dan laptop di Wi-Fi yang sama. Aktifkan Developer options → USB debugging di HP, sambungkan kabel, izinkan saat diminta. Cek dengan flutter devices.
  2. Cari IP laptop
    PowerShell
    ipconfig   # cari "IPv4 Address" pada adaptor Wi-Fi, misalnya 192.168.1.10
  3. Buka port 8080 di firewall (PowerShell Run as administrator, sekali saja)
    PowerShell (Administrator)
    New-NetFirewallRule -DisplayName "rombong-api 8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow -Profile Private
  4. Jalankan dengan alamat laptop (ganti IP-nya)
    PowerShell · folder rombong-app
    flutter run --dart-define=API_BASE_URL=http://192.168.1.10:8080/api/v1
    Cek dulu dari browser HP: http://192.168.1.10:8080/health harus menampilkan status ok.

④Coba alur lengkapnya

Klik untuk mencentang. Semua fitur ini sudah ada di aplikasi.

  • Daftar akun pelanggan baru dari layar Daftar, lalu login
  • Katalog: ketik kopi di kolom cari, pilih chip Makanan Ringan, tarik ke bawah untuk refresh
  • Buka detail Kopi Arabika Gayo, atur jumlah 2, Tambah ke keranjang
  • Keranjang: tekan + beberapa kali dengan cepat (angka langsung berubah), geser item ke kiri untuk menghapus
  • Checkout → Buat pesanan; badge keranjang kembali 0 dan detail pesanan terbuka
  • Detail pesanan → Bayar → Bayar sekarang; status menjadi Dibayar
  • Logout (ikon keluar), login sebagai admin admin@example.com
  • Admin: ikon admin → tab Pesanan → buka pesanan → Ubah status ke Diproses
  • Admin: tab Produk → ⋮ → Ubah stok Kopi Luwak; lihat perubahannya di katalog pelanggan
  • Rebutan stok: dua akun memasukkan Kopi Luwak (stok 1) ke keranjang, checkout bergantian; yang kedua ditolak

⑤Menjalankan test

Backend (butuh Go)

folder rombong-api
go test ./...                              # unit test
docker compose up -d postgres redis
go test -tags integration ./tests/...      # integration test
Integration test memakai database ecommerce_test yang dibuat otomatis saat volume PostgreSQL pertama kali dibuat. Kalau tidak ada, jalankan docker compose down -v lalu up lagi. Tanda -race di Makefile butuh compiler C (gcc), jadi di Windows lebih mudah tanpa -race.

Aplikasi Flutter

folder rombong-app
flutter analyze   # cek kesalahan kode
flutter test      # 91 test
Ini pertama kalinya kode Flutter dicompile. Kalau ada error, salin seluruh output ke Claude.

!Kalau ada masalah

"Tidak bisa terhubung ke server" di aplikasi
  • Backend menyala? Cek localhost:8080/health di browser laptop.
  • Android: sudah menambahkan usesCleartextTraffic="true"? Setelah mengubah manifest, hentikan aplikasi (q) lalu flutter run lagi; hot reload tidak cukup.
  • HP fisik: pakai IP laptop + firewall dibuka, bukan localhost.
  • Chrome: pakai --web-port 3000.
Docker: "error during connect" / "cannot find the file specified"Docker Desktop belum jalan. Buka aplikasinya dan tunggu sampai Engine running.
"port is already allocated" (8080, 5432, atau 6379)Port dipakai program lain. Untuk 5432 biasanya PostgreSQL yang terinstal di Windows: hentikan service-nya (Services → postgresql → Stop), atau ubah baris "5432:5432" di docker-compose.yml menjadi "5433:5432". Cek pemakai port: netstat -ano | findstr :8080.
Login admin gagal (401)Akun admin dibuat dari setelan saat backend pertama menyala. Kalau pernah diubah, reset data dengan docker compose down -v lalu docker compose up.
Katalog kosongBelum menjalankan skrip langkah ②, atau data baru saja direset dengan down -v.
Skrip PowerShell: "running scripts is disabled"Jangan simpan sebagai file; tempel langsung ke jendela PowerShell. Kalau ingin sebagai file: powershell -ExecutionPolicy Bypass -File seed-produk.ps1.
Flutter: "requires SDK version >=3.9.0" atau error RiverpodVersi Flutter terlalu lama. Jalankan flutter upgrade (butuh 3.35+), lalu flutter pub get.
Flutter: "No connected devices" / emulator tidak munculJalankan flutter doctor dan ikuti sarannya (biasanya flutter doctor --android-licenses). Pastikan emulator sudah menyala sebelum flutter run.
"make" is not recognizedNormal di Windows. Pakai perintah aslinya, misalnya docker compose up untuk make up, go test ./... untuk make test.
Git: "detected dubious ownership"Terjadi di drive eksternal. Jalankan git config --global --add safe.directory "*".
